# Jonathan Veículos

Crie um site institucional premium para uma loja de veículos chamada Excelência Multimarcas.

O objetivo é transmitir confiança, qualidade, credibilidade e sofisticação, com um design moderno e impactante, inspirado em concessionárias de alto padrão.

Identidade Visual

Utilize exclusivamente as cores da marca:

 Preto (#0B0B0B) como cor predominante

 Amarelo (#FFC400) para destaques

 Vermelho (#E30613) apenas para detalhes e CTAs importantes

 Branco para textos e contraste

O visual deve ser elegante, moderno e tecnológico.

Evite qualquer aparência de template pronto.

Observações Importantes

 Não utilizar imagens genéricas de carros esportivos; priorizar veículos de passeio e SUVs compatíveis com uma loja multimarcas.

 Utilizar a identidade visual da Excelência Multimarcas (preto, amarelo e vermelho) em todo o site.

 Criar uma experiência visual premium, com aparência de empresa consolidada e de alto padrão.

 Estruturar o projeto em componentes reutilizáveis e manter o código organizado para facilitar futuras expansões, como integração com um estoque dinâmico e painel administrativo.
